## 🛠️ Highlighted Projects

Here are the projects I have developed, organized by technical domain:

### 🚁 Autonomous UAV Guidance & Landing Stack
*   **[vision-guided-uav-autonomous-landing-system](https://github.com/nhelal96/vision-guided-uav-autonomous-landing-system)**: A modular ROS-based navigation and flight stack. It integrates pre-flight takeoff supervision, Perspective-n-Point (PnP) pose homography docking, depth map terrain segmenter, and OpenCV texture variance check loops to land safely on target pads.

### 🚗 Autonomous Vehicle Control & Simulation
*   **[autonomous-vehicle-telemetry-and-closed-loop-control](https://github.com/nhelal96/autonomous-vehicle-telemetry-and-closed-loop-control)**: A closed-loop control pipeline inside the CARLA simulator, combining synchronized sensor telemetry data collection and classical PID controllers (speed tracking and lateral yaw heading error geometries).

### 🧠 Deep Reinforcement Learning Policy Optimization
*   **[deep-rl-autonomous-maneuvering-agents](https://github.com/nhelal96/deep-rl-autonomous-maneuvering-agents)**: An RL training testbed containing custom Gymnasium simulation environments (Ball Blast) and model-free policy learning implementations (PPO surrogate clipping and SAC soft-Bellman entropy optimization).

### ♟️ High-Performance Systems Engineering
*   **[caesar-chess-engine](https://github.com/nhelal96/caesar-chess-engine)**: A standalone, optimized chess engine written in C. It represents board layouts using 120-square mailboxes and 64-bit bitboards, optimized with Alpha-Beta minimax, Iterative Deepening, Transposition Tables (Zobrist keys), and MVV-LVA move ordering.
