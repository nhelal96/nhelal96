## 🚀 Open-Source Systems (Public Repositories)

Here are some of my open-source projects, detailing robotics control stacks, simulation environments, and high-performance algorithms:

### 🚁 UAV Autonomous Landing & Flight Stack
*   **[vision-guided-uav-autonomous-landing-system](https://github.com/nhelal96/vision-guided-uav-autonomous-landing-system)**: A complete ROS-based flight stack. It integrates pre-flight takeoff supervision (`uav-safe-takeoff`), Perspective-n-Point (PnP) pose homography tracking (`uav-qr-docking`), depth map point cloud segmenter (`uav-terrain-segmentation`), and landing node controls (`uav-safe-landing`).

### 🚗 Autonomous Driving Telemetry & Control
*   **[autonomous-vehicle-telemetry-and-closed-loop-control](https://github.com/nhelal96/autonomous-vehicle-telemetry-and-closed-loop-control)**: A closed-loop control system in the CARLA simulator. It coordinates a frame-synchronized telemetry and sensor logging pipeline (`carla-data-collection`) and dual lateral/longitudinal PID feedback controllers (`carla-pid-control`).

### 🧠 Deep RL Autonomous Maneuvering Agents
*   **[deep-rl-autonomous-maneuvering-agents](https://github.com/nhelal96/deep-rl-autonomous-maneuvering-agents)**: An RL training suite. It implements continuous maneuvering driving agents in CARLA (PPO and SAC models) and a custom 2D Gymnasium environment (`ball-blast-gym-env`).

### ♟️ High-Performance Chess Engine
*   **[caesar-chess-engine](https://github.com/nhelal96/caesar-chess-engine)**: A standalone, high-performance chess engine in C using 120-square Mailbox and 64-bit Bitboard representations, optimized with Alpha-Beta minimax, Iterative Deepening, Zobrist Hashing (Transposition Tables), and MVV-LVA move ordering.
